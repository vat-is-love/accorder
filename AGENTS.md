# accorder

Редактор текстов песен и аккордов. Статическая веб-версия в `dist/` хранит библиотеку в IndexedDB без Node.js; локальный запуск `server.mjs` сохраняет файловый режим с `songs/` и `exports/`. Публикуется только `dist/`; личные песни и экспорты в репозиторий и архив публикации не включать.

Перед работой прочитать [README.md](README.md) (реализованные функции, запуск и формат данных) и [TODO.md](TODO.md) (планы), затем актуальные файлы, которых касается задача.

- Сохранять пользовательские изменения и содержимое `songs/`. Не переписывать песни автоматически и не менять входные данные или код ради документации.
- Делать запрошенное без несогласованных функций, инструментов, украшений и общего переделывания проекта.
- В интерфейсе использовать только короткие функциональные заголовки, подписи, кнопки, необходимые подсказки клавиатуры и сообщения о состоянии или ошибках. Не добавлять слоганы, рекламные и эмоциональные тексты, декоративные примеры или новый копирайтинг без прямой просьбы пользователя.
- Не спрашивать повторное подтверждение для уже явно разрешённых обычных правок. Соблюдать реальные ограничения среды и обязательные системные разрешения; не обходить отказ или ожидающее разрешение.
- Браузерную проверку пользователь выполняет сам. Не открывать браузер и не запускать такую проверку без новой явной просьбы пользователя.
- Не запускать и не перезапускать пользовательский сервер без необходимости задачи или просьбы пользователя; не останавливать его сервер для своих проверок.
- Использовать подходящие небраузерные проверки по характеру изменения. Не выдавать непроведённые проверки за выполненные; сообщать об ограничениях. Для документационных правок достаточно сверки с кодом и проверки ссылок, без запуска тестов и сервера.
- Поддерживать описание реализованных возможностей в README в соответствии с изменениями поведения. Новые принятые правила работы сохранять в этом файле.
- Отделять реализованное от планов. TODO — редактируемый список будущих задач, а не разрешение самостоятельно реализовывать весь список. Добавлять или реализовывать планы только в рамках запроса пользователя.
